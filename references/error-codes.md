# XS 錯誤代碼對照表（官方）

> 來源：XQ 官方 lesson 教學站各類「錯誤代碼說明」。四類腳本各有**獨立**的錯誤碼集合，數字相同不代表同一件事。
> 平台常只顯示代碼不附原因；查不到就對照本表。排除不了時多半要匯出腳本 + `C:\SysJust\XQLite\LOG` 寄 XQservice@XQ.com.tw。

## 共通除錯守門碼（最該先看的幾個）

| 情境 | 代碼 | 意義 |
|---|---|---|
| **look-ahead（偷看未來）** | 選股 `50020` | 「嘗試取得未來資料，請注意 [] 是否使用負數」— `[-N]` 取未來會被擋 |
| **自訂 RaiseRunTimeError** | 指標 `1011`／交易 `1301`／雷達回測 `18`／選股 `50017` | 腳本自己丟的錯（若有自訂訊息會顯示），先查自己的防呆條件 |
| **最大引用筆數不足** | 指標 `1010`／選股 `50305`／雷達回測 `19` | 引用範圍 > 已載入資料，調大 `SetTotalBar`/`SetBarBack`（跨頻率見 anti-patterns #22） |
| **除以零** | 選股 `50501`／雷達回測 `26` | 分母沒判 `<> 0` |
| **不支援的語法** | 指標 `1043`／交易 `1102`／雷達回測 `34`／選股 `50508` | 混到其他平台語法或該腳本類型不支援 |
| **腳本版號不符需重編** | 指標 `1034`/`1039`／交易 `1000`／雷達回測 `21`／選股 `50021` | 重新編譯即可 |
